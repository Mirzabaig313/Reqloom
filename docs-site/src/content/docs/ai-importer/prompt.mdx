## Notes

The prompt is deliberately long. Nearly all of it is the schema reference and a
worked example, and that's the point — a model that can see the real key names,
the eleven exact auth strategy values, and the reference grammar has very little
left to invent. Shortening it trades directly against accuracy.

Two rules in it do the heavy lifting:

- **Never invent a path, field, or status code** — anything ungrounded goes under
  Open questions instead. A plausible wrong `expect_status` looks correct and
  fails on contact.
- **Plan before YAML** — Part 1 is a five-minute review gate, where a wrong
  assumption is one sentence rather than forty lines of buried YAML.
